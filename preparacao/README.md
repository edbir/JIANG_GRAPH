# Preparação — Material para o TCC (Artigo)

Esta pasta contém material de preparação para a escrita do artigo acadêmico. Cada arquivo corresponde a uma seção do TCC e define: o que cobrir, como estruturar, e o que estudar antes de escrever.

## Conteúdo

| Arquivo | Seção do TCC | Status |
|---------|-------------|--------|
| `01_introducao_prep.md` | 1. Introdução | Escopo definido |
| `02_conceitos_tecnologias_prep.md` | 2. Conceitos e Tecnologias | Escopo definido |
| `03_infraestrutura_e_dependencias.md` | (Operacional) | Decisões fechadas |
| `04_trabalhos_relacionados_prep.md` | 3. Trabalhos Relacionados | Escopo definido |
| `05_desenvolvimento_prep.md` | 4. Desenvolvimento | Escopo definido, implementação pronta |
| `06_avaliacao_prep.md` | 5. Avaliação | Escopo definido, aguarda dados reais |
| `07_conclusao_prep.md` | 6. Conclusão | Escopo definido, aguarda avaliação |

## Como usar

1. Leia o prep da seção que vai escrever
2. Estude as sugestões de leitura
3. Consulte a implementação referenciada (em `src/` e `docs/`)
4. Escreva a seção no TCC.md (ou Google Docs)
5. Revise com o Kiro

## O que NÃO está aqui

- Explicações de design de módulos → `docs/design/`
- Referências técnicas rápidas → `docs/`
- O artigo em si → `TCC.md` (backbone) + Google Docs (versão final)
